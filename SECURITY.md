# Security

## Reporting a vulnerability

Report it privately, through either channel:

- **GitHub:** the **Report a vulnerability** button on this repository's
  [Security tab](https://github.com/ArmornetIO/showcase/security/advisories/new).
- **Email:** [security@armornet.io](mailto:security@armornet.io).

Please do not open a public issue, pull request or discussion for a
vulnerability. That publishes it before there is a fix.

A useful report says which version or commit is affected, what an attacker can
do, and the smallest steps that show it. A proof of concept helps; a fix is
welcome but not expected.

## What happens next

| Step | Within |
|---|---|
| We acknowledge your report | 3 business days |
| We confirm it, or explain why we don't consider it a vulnerability | 10 business days |
| We publish an advisory with the fixed version | 90 days of your report, sooner once a fix ships, later only if we agree it with you |

The advisory credits you under the name you choose, unless you would rather
not be named.

## Supported versions

This project is in alpha. Only the latest release receives security fixes.
